# ICPC India Regionals: Problem Sets & Solutions

My solutions to past **ICPC India Regional** problem sets, written in C++ as practice for the real thing. Each contest folder holds the problem statements, where I have them, next to my solutions.

All solutions here are correct: I've stress tested them myself. Feel free to use them as reference solutions for stress testing your own code.
