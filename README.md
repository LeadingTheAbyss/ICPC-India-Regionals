# ICPC India Regionals: C++ Solutions (Amritapuri, Kanpur & more)

Stress-tested C++ solutions to past **ICPC India Regional** problem sets (ACM ICPC Amritapuri and Kanpur regionals, 2006 to 2024), with a topic-wise index. Each contest folder contains the problem set (where available) along with my code for it.

All solutions here are correct: I've stress tested them myself. Feel free to use them as reference solutions for stress testing your own code.
